# 校准与验收细分流程：P5～P8

接续[复刻总流程](replication-workflow.md)，只执行已选且具备前置条件的模块。实体动作遵守用户授权和现场条件；已经明确的授权不重复索取。长请求超时先查后端状态，不能重发归位、加热、挤出或接触动作。

每次独立验收结束记录加热目标、风扇、检测使能、运动限值和电机保持状态，按该次动作的约定恢复；不把冷拔保留90°C等特定结束行为当成所有测试的收尾方式。

## P5：通信、真实归位与基础检查

输入：P4 Ready、实际硬件状态及任务范围。仅元数据等不需要运动的任务可省略归位和后续几何标定。

1. 先做不产生 XYZ 运动的检查。双 Z 读取原 Z/Z1 的 TMC 寄存器，确认新增 UART；成功只说明通信，不证明侧别、相序或正向。风扇通道与加热器/探针配置也须对应实际接线。
2. 在授权及用户已准备观察时，分别验证主/辅助风扇原生控制与 M106/M107 路由。使用短时输出后恢复原状态，记录实际哪个风扇响应，不能仅看网页滑块。
3. FAN4 用短暂使能电机且不转动的方式观察启动，按原使能状态恢复；全体释放后延时约 60 秒停止。不要为了关风扇释放保持龙门的 Z；Z 锁定时持续运行是预期。若此时不适合释放所有电机，启动检查和延时停止检查分开记录。
4. 进行任何后续 XYZ 动作前，确认机器空闲、用户在旁、归位路径/抬升余量/探针/线序具备安全条件，完成本次启动的真实三轴 G28并检查成功。RESTART/FIRMWARE_RESTART/进程重启或重新上电后都需重新确认，界面和 homed_axes 不足为证。
5. 不能先安全归位时，停在这里让用户检查线序、方向、探针或机械状态，必要时恢复已知可归位的装配；不得用 FORCE_MOVE、SET_KINEMATIC_POSITION 或伪造 homed 标志绕过。归位本身也是运动，不能为满足流程而盲归位。
6. 验证 PA11 能正常触发、归零与重复测量，检查软限位和探针/喷嘴几何。已有原厂手动 Z/首层基准先保留记录；未通过 PA11 基础时，不进入 Z_TILT、擦嘴或 ADXL 接触。

完成：已选电气通道结果明确；需要运动的任务有本次启动真实归位和可用 PA11 基础。

失败处理：通信回到模块/供电/跳线/地址检查，归位失败停止后续运动，PA11 异常先排查探针。具体条件见[归位规则](../../../docs/validation.md#上电与重启后的归位规则)。

## P6：按所选模块逐项标定

### P6.1：独立双 Z

输入：P5 通过、拆除同步联动、用户可观察，具备小幅动作的安全余量。

1. 从打印机正面定义左右，分别规划低速小幅动作并让用户观察实际通道和正向。每次只测试一个通道，记录“stepper_z → 哪侧”“stepper_z1 → 哪侧”；看不清就重做受控观察，不能猜。方向不正确时停止并针对该通道适配；重载后重新满足 P5 归位规则。
2. 测量两根丝杆相对于目标坐标系的位置和中心距。z_positions 第一行对应 stepper_z，第二行对应 stepper_z1；参考 -25/455 和 480mm 不能替代目标测量。
3. 结合实际 probe XY offset、床面和行程选择左右各三个靠近中部的喷嘴探点。检查其对应探针位置都可落床，包含移动时的安全高度；[参考几何](../../../docs/hardware.md#左右映射及自动调平坐标)用于理解换算。
4. 确认横梁无明显失衡或机械卡滞后执行受控 DUAL_Z_LEVEL，观察倾斜调整是否趋于正确方向、是否收敛及后续 Z 归位。它会清除旧网格，调整后重新测网，不能加载调整前的旧形状充当新网格。

完成：实际侧别、正向、几何及调整后归位均有证据。普通 G28 不自动 Z_TILT；完整开始流程由包装宏在适当位置调用。

失败处理：越调越歪先检查侧别/顺序/方向；不收敛检查床面局部形状与机械问题，不能不断放宽容差。

### P6.2：擦嘴位置与床网几何

输入：P5 基础及目标机测量；有双 Z 时其调整先通过。仅床网任务跳过擦嘴部分。

1. 先测擦嘴条位置、有效 X 范围、Y 接近路径、喷嘴接触高度和工具头/热床接线间隙，建立所用坐标与临时 offset 的对应关系。参考 Y430/Z-0.5/-2 均非目标机默认值。
2. 在已真实归位后先验证安全高度下的非接触路径，再按授权与测量值受控确认硅胶接触。位置/高度未确定时不执行原开始代码的低 Z 或高速擦拭；确认几何后再验证热擦、冷擦、排料与拉断动作。排料前核对耗材温度、单次挤出限距和速度，不照搬原厂过大的挤出面积上限来绕过保护。
3. 检查 PA11 可测范围、网格参数和 ADXL 接触区域的可达性。完整方案的床网包含中心±3mm及量化余量；只选自适应床网时使用 P4 适配后的独立命令入口。
4. 先用 PLAN_ONLY 核对普通模型和有明确 PA 标记的文件范围、点数与算法，再受控测实际床网。规划范围正确不证明所有探点物理可达。
5. 选择参考温漂修正时完成[专项D4小网格验收](adaptive-mesh-drift.md#d4小网格实际验收p5p6)：核对180秒保持、每5点中心三次中位数、末组、时间插值及实际矩阵。普通BED_MESH_CALIBRATE/G29不自动使用此项；不要拿它们代替新入口的验证。
6. 验证双 Z 调整在擦嘴/新网格之前，擦嘴临时 offset 在新网格/正式 ADXL 前清除；不可把擦嘴基线或旧网格叠加进新的首层基准。

完成：擦嘴几何/路径和所选床网的计划及实测各自有结果；缺少擦嘴硬件时不进入完整自动擦嘴流程，也不伪造会话。

失败处理：路径不可达先修正实际几何；PA 文件出现全床大网格先查范围解析，不能单靠无限延长擦嘴授权。见[切片事项](../../../docs/slicer.md)及[超时经验](../../../docs/lessons-learned.md#pa-校准超时要先看范围和第一个错误)。

### P6.3：ADXL 喷嘴 offset

输入：PA11 基础、匹配 Tap MCU/主机模块、传感器与 raw 轴确认、目标原始坐标基准和覆盖接触区域的已测床网。

1. 核对本次选用的配方及源码安全门、同点 PA11 对齐、raw Z 下限、接触窗口、manual_baseline 和允许偏差。先从已验证的 PA11/手动首层基准和机械测量确认物理关系；缺少基准时先补目标标定，不孤立复制 probe.z_offset=0 或 -2。不能证明限位/窗口合理时不接触。
2. 解释热床首层目标、连续热稳定等待、喷嘴准备温度和本次动作。按适配计划运行 ADXL_Z_OFFSET_CHECK 高位无接触检查；该命令会加热、真实归位并运动，不是只读查询。先确认其整个下探仍悬空，不降低阈值换取通过。
3. 用户确认喷嘴干净、空间和停止方式后，用 FUZZ=0 先在固定接触点做受控测量，核对同点 PA11 coarse、每个 Tap 的 coarse+5 起始、三个触发值、极差、窗口、回抬和实际 mesh 值。APPLY=0 的预览仍会加热/归位/碰床，不能当成无运动测试。
4. 固定点通过后再验证随机接触：FUZZ=3 每次选一个 XY，三个样本及有界重试同点，offset 使用实际 XY 的床网值。记录 contact start/fuzz/group 及最终 offset，不凭一句成功提示判断首层正确。
5. 完整打印准备验证一次性会话链：PREPARE_WIPE 热稳定/真实归位/高位检查 → 所选双 Z 包装 → 擦嘴 → 清临时偏移 → 新 PA11 床网 → 同文件、同床温、SOAK=0、AFTER_WIPE=1 的正式测量。单次授权失败也消耗；不能手工改标志、重复利用授权或在流程中再乱插 Z_TILT。

完成：无接触检查、接触重复性、偏移计算和清洁会话链分别有实机证据，之后才进入首层。部署后的 Ready 或离线测试不算这些结果。

失败处理：明确无触发按现有整组、最多三组逻辑处理，部分样本不拼凑；通信、恢复/回抬、位置或窗口异常停止接触。先保存第一个错误和状态，再排查，不重复更深下探。详见[工作原理](../../../docs/features.md)及[精选经验](../../../docs/lessons-learned.md)。

### P6.4：可选调参、元数据与冷拔

1. autotune：确认输入电机参数和所选轴，与原厂已有驱动配置合并后读取状态；插件不是自动测电机参数的工具。目标有正确参数才做所选运行验证，观察电机温升/失步等，不能把近似 QIDI 条目当成所有原装挤出机规格，也不默认给两个 Z 开启 autotune。
2. 元数据：以实际 Bambu 文件检查总层数/高度/预览及权限，当前旧 Fluidd 层数是 Z 估算；验证在 P7 上传文件时完成，不为此执行归位或接触。目录权限问题只处理实际相关目录。
3. 冷拔：先核对材料、250°C 温度能力、Z200 行程、150mm 挤出限制、90°C 回抽保护、辅助风扇及 beeper。保护不满足时说明并另行适配，不静默把 min_extrude_temp 降为70。先单独短响确认提示音，50% PWM 是参考试听结果，不是通用低音量。
4. 在授权及现场条件满足时再验证冷拔完整序列，确认辅助降温开/关、90°C 回抽、仅释放挤出机及完成后目标90。空闲时调用宏；作为 virtual SD 维护任务使用展开文件，不能仅写 COLD_PULL 宏调用来绕过空闲保护。

完成：只记录实际选中并验证的项目。独立维护动作不并入打印开始流程；材料或保护条件不满足时记录未实现，而非宣称全功能完成。

## P7：切片、完整准备与首层验收

输入：用户选中的运动/接触模块已通过，目标机预设及材料条件。

1. 将 3MF 作为 Bambu 项目打开并保存目标用户预设，选择自己的设备/材料。按目标硬件组织开始代码；未选 ADXL/擦嘴/双 Z 时移除或改写对应调用和依赖，不能仅在完整参考代码里注释一个动作后假设其余安全。仅双 Z 时在新床网之前调用 DUAL_Z_LEVEL，并保留目标 PA11/手动首层基准；未实现擦嘴会话的方案不能残留 AFTER_WIPE 调用。
2. 对照[切片说明](../../../docs/slicer.md)处理 SET_SKEW 是否存在、当前排料高度/回抽、擦嘴范围、目标首层修正、运动基准恢复、M106 P2 路由、结束关闭辅助及仅释放 X/Y/E 等事项。不要用历史测试 fixture 替换用户最新首尾代码。
3. 生成实际 G-code 并核对首层范围、PA 校准标记、温度/等待、几何/坐标、命令存在和功能顺序。PLAN_ONLY 和语法检查先做，3MF 成功打开不能作为部署验收。
4. 首次选择便于观察的小模型/首层测试，用户在旁运行一次完整准备，观察归位、所选 Z 调整、擦嘴、床网、接触、重新升温和排料线是否按计划完成。热稳定时没有运动属正常等待，HTTP超时先查状态而不重发。
5. 观察首层并调整目标机自己的微调值，记录材料、床温、版本、测量 offset 与结果；不直接接受参考 +0.140。确认正常结束的热目标、主/辅助风扇、停车、网格与电机保持状态。
6. 检查已有取消/空闲/故障路径对新增功能的处理，并区分静态检查与授权范围内实测。断电恢复整套组合尚未专门验收，不为了填满记录擅自做断电/故障试验。仅元数据任务到文件/界面结果即可，不要求试印。

完成：实际切片文件、完整准备与首层结果明确；未做的退出/恢复测试标明边界。

失败处理：保存首个错误和当前状态；会话过期查实际范围与耗时，首层问题查 PA11/mesh/旧 offset/材料微调。回到对应 P5/P6 模块，不整体重装、扩大窗口或直接加参考补偿。

## P8：交付、恢复与后续接手

1. 汇总所选功能、实际部署文件/哈希/服务、目标机侧别/几何/标定及已验证结果；未完成或只做计划/模拟的项单列。
2. 给用户日常入口：如何使用目标 Bambu 预设、双 Z 调整何时发生、可选维护如何运行，及每次重启后先真实 Home 的提醒。实现细节保留在目标机记录和专题文档。
3. 交付可用的配套备份和逐文件回退映射；回退前检查用户是否有后续修改，在空闲及授权范围内恢复实际服务关系和对应模块，重新满足归位规则。不要为交付演示自动回退正常机器。
4. 继续任务时先核对实时状态、当前版本、最近重启和已完成证据，再从未完成阶段继续；不能依旧记录推断仍归位或盲重发最后一个实体动作。
5. 若用户要公开复刻成果，导出所需脱敏文件和验证结论；不发布私有目标机记录、地址、密钥、备份或原始日志。保留第三方来源，未完成另一台验证不能宣称全系列兼容。

完成：人能日常使用，下一位智能体能定位当前阶段、证据、未完成项和恢复路径。
