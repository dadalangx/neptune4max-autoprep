# Neptune 4 Max AutoPrep｜打印自动化改进项目

让海王星 4 Max 自动完成更多打印前准备，减少重复找平、擦嘴和首层高度调整。本项目提供已使用方案的源码、参考配置和智能体指南，你可以让 Codex 等智能体按自己的机器和所需功能完成适配。

参考机器由机主确认运行正常；完整方案尚未在第二台原装 4 Max 上完成复刻验收，需要逐项检查和标定。

## 能带来什么

| 功能 | 使用体验 |
|---|---|
| 独立双 Z | 打印前自动校正龙门两侧高度 |
| 自动喷嘴 Z 偏移测量 | 在清洁喷嘴后自动测量首层高度基准 |
| 自动打印准备 | 串联热床稳定、排料、硅胶条擦嘴与校准 |
| 自适应床网与温漂修正 | 按模型范围测网，并通过中心参考减少扫描期间的漂移影响 |
| 风扇控制改进 | 独立控制辅助冷却，驱动散热按需开启，主风扇保留完整调节范围 |
| 冷拔维护 | 用维护宏或 G-code 完成设定的冷拔流程 |
| Bambu Studio 适配 | 提供项目预设和首尾代码，改善网页端打印信息识别 |
| 原厂环境适配 | 保留原厂软件环境，按实际版本合并需要的改动 |

可以只选择部分功能。独立双 Z、擦嘴和风扇改动需要相应的硬件装配；完整方案可使用 **MKS TMC2209 V2.0** 和**拓竹 A1 适用硅胶擦嘴条**。先查看[采购清单与装配步骤](docs/bom-and-assembly.md)，再让智能体结合[硬件说明与实物照片](docs/hardware.md)确认你所选功能的物料和装配要求。

## 如何使用

1. 点击 GitHub 的 **Code → Download ZIP**，下载并解压项目。
2. 在能读取本地文件、执行 SSH 的智能体中打开解压目录，例如 Codex。提供自己的打印机地址，以及想实现的功能。
3. 复制下面的提示词，让智能体先检查机器、整理适配方案与备份，再按阶段实施。
4. 按提示完成断电装配、尺寸测量和现场观察，逐项验证后再进行首层试印。

> 请读取这个项目中的 skills/neptune4max-mods/SKILL.md，按其中的复刻流程适配我的海王星 4 Max。打印机地址：`<你的打印机地址>`；想实现的功能：`<完整方案或列出所需功能>`。先检查现有环境、硬件和配置，给出适配差异与备份方案，再在我的授权范围内逐阶段实施。需要现场装配、测量或观察时告诉我具体要做什么，并记录已完成及尚未验证的步骤。

打印机地址可以从屏幕或路由器查找。常见原厂 SSH 账号为 `mks`、密码为 `makerbase`；若已修改，使用自己的凭据。项目不会自行执行安装，下载文件或读取 skill 也不会自动改动打印机。使用者仍需完成实体装配并配合现场验证。

大致过程是：检查机器 → 按功能适配 → 装配与标定 → 首层验收。详细分步骤流程由智能体从 skill 中按需读取。

**上电或重启 Klipper 后，先真实归位，再移动工具头或校准床网。** 界面的默认位置和“已归零”状态可能与真实位置不同；未真实 Home 时不要随意移动，也不要点击网页端“校准床网补偿”。归位条件由智能体按[验收指南](docs/validation.md#上电与重启后的归位规则)核对。

## 使用 Bambu Studio 预设

完成打印机端适配及基础验收后，在 Bambu Studio 中将 [naptune4max.3mf](slicer/naptune4max.3mf) 选择为**打开项目**，载入其中的打印机、工艺和耗材设置，再另存为自己的用户预设。

项目内包含参考设置和 3DBenchy；独立的[开始代码](slicer/start_gcode.txt)与[结束代码](slicer/end_gcode.txt)也已提供。让智能体根据你的硬件、擦嘴位置及首层标定修改自己的预设，重新切片后使用。**不要在尚未完成装配和标定的原装机器上直接运行预置开始代码。** 具体适配事项见[切片说明](docs/slicer.md)。
