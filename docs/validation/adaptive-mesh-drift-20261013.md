# 实机集成验证记录

完成时间：2026-10-13 05:48:29 UTC+8。结果：通过。

本轮验证的是实际 XY 扫描、中心参考插值和最终床网矩阵之间的连接。它不是对完整打印效果的测量，也不能据此宣称所有热误差均已消除。

## 实机流程

- 热床 60°C、喷嘴 140°C；主模型风扇、辅助风扇关闭。
- 部署重启后，先调用现有 DUAL_Z_LEVEL，完成真实 XYZ 归位与双 Z 调整。
- 使用原 ADAPTIVE_BED_MESH 接口，模型范围 X180～220/Y180～220、MARGIN=10，原边界解析器继续预留 ADXL 接触覆盖区。
- 生成 4×4 共 16 个实际网格点；中心参考位于热床坐标 (215,215)，本机对应喷嘴 (239.25,194.55)。
- 近床保持实际 180.333 秒，再独立三次探测取中位数为基准。
- 在第 5、10、15、16 点后追加三次探测取中位数；最后只有一点的一组同样得到前后参考值。
- 网格扫描及参考阶段约 72.495 秒，不含归位、加热和180秒保持。
