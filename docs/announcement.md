# 发布文案

## GitHub 项目简介

海王星 Neptune 4 Max 改装参考：独立双Z、ADXL喷嘴Z偏移、擦嘴、自适应床网、Bambu Studio适配，以及供Codex等智能体使用的skill。

## 中文发布帖

把自己的海王星4Max改装过程整理成了开源项目，分享给同样想折腾这台大尺寸打印机的朋友。

这套方案保留原厂工具头、热端、挤出机、电机和热床，在原厂软件环境上逐步增加独立双Z、打印前龙门校正、ADXL喷嘴接触测量Z偏移、硅胶条擦嘴、自适应床网和独立辅助风扇。还整理了冷拔维护宏、主风扇比例映射、Bambu文件元数据适配，以及旧Python环境的兼容改动。

新增Z驱动统一为机主实际验证使用的MKS TMC2209 V2.0，主板E1只短接UART，R110模块使用0.110Ω采样电阻配置。接线、方向和调平坐标的确认方法都放在项目里。

分享方式是“改装思路＋源码＋参考配置＋AI skill”。你可以让Codex等智能体先读取项目和你的打印机环境，再按所需功能完成适配；无需先成为Linux专家，但硬件接线、首次接触和首层仍需要人在机器旁逐项确认。

项目提供我的Bambu Studio 3MF项目，以及独立的开始/结束G-code。打开项目即可查看和载入项目内设置，保存为自己的用户预设；其中单机擦嘴位置和首层修正需要重测。

目前完整组合来自一台实际使用的改装机，还没有在第二台原装4Max完成整套复刻验收。欢迎分享脱敏环境报告、接线照片、复刻结果和适配补丁，一起把支持范围做实。

项目：https://github.com/dadalangx/neptune4max-ai-mods
