# 采购清单与具体硬件改装

## 改装需要准备哪些配件和工具？

本方案主要复用海王星 4 Max 的原厂硬件，无需更换原装电机、丝杆、挤出机、热端和热床。按自己需要的功能准备配件：独立双 Z 需要新增驱动及独立电机接线，自动擦嘴需要硅胶擦嘴条和固定材料；辅助模型散热和驱动散热改接均复用机器自带的风扇。

下列数量以参考机器的改装方式为基础。购买前先拍照记录主板、现有插头及线束，确认生产批次、已有改装和实际线长。

### 一、独立双 Z 与自动擦嘴所需配件

| 配件 | 参考数量 | 用途及选购注意事项 |
|---|---|---|
| MKS TMC2209 V2.0 步进电机驱动模块 | 1 个 | 安装在 E1，新增一个独立 Z 驱动通道。参考模块两颗采样电阻均为 R110，对应 `sense_resistor: 0.110`。核对实际型号、版本及电阻丝印。 |
| UART 短路帽 | 1 个 | 与主板 E1 跳线排针匹配，通常为 2.54 mm 规格；若驱动套装或现有备件已包含，可直接复用。 |
| 与主板 Z/E1 插座匹配的 4P 胶壳 | 通常新增 1 个 | 保留一路原插头、只重做另一路时需要 1 个；两路都重做时需要 2 个。常见售卖名为“XH2.54”，购买前核对间距、外形和卡扣。 |
| 与胶壳及线径匹配的压接端子 | 每个新 4P 插头 4 个 | 只重做一路时至少 4 个，两路重做时至少 8 个；建议另备若干端子，端子规格应适合实际导线。 |
| 驱动模块散热片及配套固定材料 | 1 套 | 模块已附带时无需另购。安装后应牢固，避免接触针脚或其他导体，并保留风道。 |
| 拓竹 A1 适用硅胶擦嘴条 | 1 条 | 用于自动擦嘴，固定在热床接线末端的塑料支架上。 |
| 擦嘴条固定材料 | 按需 | 根据实际支架选择耐温、牢固的固定方式；本项目照片提供位置参考，不能据此假定所有批次都能直接粘贴安装。 |

**胶壳规格说明：** JST 官方 XH 系列的标称间距为 **2.50 mm**。市售“XH2.54”的名称可能不严谨，应以与原插座实际匹配为准，不能把所有 2.54 mm 四针插头视作通用。这里的胶壳间距与 UART 短路帽间距是两项不同规格。[JST XH 官方资料](https://www.jst-mfg.com/product/index.php?lang=2&series=277)

### 二、原厂风扇复用与按需线材

| 配件或材料 | 参考数量 | 何时需要 |
|---|---|---|
| 辅助模型散热风扇 | 无需另购 | 复用海王星 4 Max 自带的辅助模型散热风扇，改接 FAN3（PC9）。 |
| 步进驱动散热风扇 | 无需另购 | 将原有驱动散热风扇从 FAN6 移到 FAN4，复用原风扇。 |
| 连接线、延长线、配套胶壳及端子 | 按需 | 电机分线或风扇改接后原线长度、接口不合适时准备。电机线与风扇线应分别核对规格。 |
| 热缩管或绝缘套管 | 按需 | 对确实存在的导线接头做好绝缘；无接头时无需额外加接。 |
| 扎带或线夹 | 若干 | 固定线束并保留活动余量，避免拉扯插头、磨线或碰到运动部件。 |

主模型风扇、辅助模型散热风扇、热端散热风扇和驱动散热风扇均复用原厂硬件。风扇改接只在线长或接头不合适时，按需准备延长线、胶壳和端子。

### 三、工具

| 工具 | 用途及选择建议 |
|---|---|
| 内六角扳手 | 拆装外壳和同步带轮等部件，可复用购机附赠工具。 |
| 斜口钳 | 剪断、修整需要改接的导线。先确认接线方案，再剪线。 |
| 剥线工具 | 剥除绝缘皮，尽量保留完整铜丝；可使用适合线径的剥线钳。 |
| 小型开口端子压线钳 | 钳口需适配实际端子和线径，分别压紧导体与绝缘固定翼。不固定推荐某个型号，仅凭“SN-2549”等型号不能保证适配所购端子。 |
| 数字万用表（强烈建议） | 在电机、线束脱离主板且断电的情况下，核对线圈配对、导线通断和压接结果。 |
| 直尺或游标卡尺 | 测量擦嘴条位置与高度、丝杆位置，以及选购插头时核对尺寸。 |

不需要自行压线时，可选择正确配对、接口匹配的独立电机线束；成品线仍需检查线序、线长和接触可靠性。

## 具体需要进行哪些硬件改动？

### 1. 独立双 Z

原厂方案由同一驱动控制两台 Z 电机，两侧丝杆通过顶部同步皮带联动。改装后，两台电机分别由原 Z 与新增 E1 驱动，自动调整龙门两侧高度。

1. 断电前拍照、标记两台电机及线束的对应关系。关闭打印机电源、拔掉电源线后再拆装。
2. 拆除两侧 Z 丝杆顶部的同步皮带及两个**同步带轮**，保留其余正常的丝杆支承与传动结构。“带齿、随丝杆转动”的部件在这里称同步带轮更准确。
3. 将原本并联的两台 Z 电机线路分开，每台电机保留独立的四根导线，分别接到自己的驱动通道。分离后不能仍有电机相线跨接两个驱动输出。
4. 核对每台电机的两组线圈及插头线序，再压接端子、装入胶壳。保留原插头线序的记录，结合主板和驱动资料接线，不能只按线材颜色或统一的“1/2 脚是一组”来猜。
5. 在 E1 安装 **MKS TMC2209 V2.0** 与散热片。按模块和主板引脚标识确认方向、完整插入；参考方案**只短接 UART，M0/M1/M2 均不短接**。
6. 两台 Z 电机分别连接原 Z 和 E1。轻拉各根导线检查端子锁止，检查插头插紧、线束绝缘和活动余量。
7. 装配检查完成后，再进行 Klipper 适配及验收：先查 UART 通信并核对安全归位条件，完成真实归位后，以受控的小幅运动让现场使用者确认两侧映射与正向抬升，再配置、验证自动 Z 倾斜校正。

参考机器正面看为**原 Z 控制左侧、E1 控制右侧**。其他机器必须实测确认，智能体应记录观察结果后再设置自动调平的驱动与丝杆位置顺序。

本项不需要额外购买 Z 电机或丝杆。同步带轮拆除后两侧可独立移动，装配期间需保持龙门姿态，避免两侧产生过大的高度差。

跳线实物照片与主板引脚资料见[现有硬件说明](hardware.md)。照片为展示跳线暂未插驱动，实际运行时必须完成驱动安装。

### 2. 自动擦嘴

1. 使用拓竹 A1 适用的硅胶擦嘴条，安装在**热床后方、热床接线末端的塑料支架上**，参考项目中的安装照片。
2. 确认固定牢固、受热后稳定，线束不会被擦嘴条或工具头挤压；核对工具头及热床移动的整个路径，留出安全间隙。
3. 测量自己的擦嘴接触位置、高度和可用行程，再由智能体生成路径。完成安全归位与高位路径验证后，再逐步验证接触擦拭。

不需要重新设计整套工具头。参考机器的擦嘴坐标、接触高度和临时 Z 偏移属于本机标定结果，其他机器应重新测量。

实物照片见[硅胶擦嘴条安装图](images/a1-wiper-installation.jpg)。

### 3. 辅助模型散热风扇

1. 复用海王星 4 Max 自带的辅助模型散热风扇，核对改接后的线长和插头，无需另购辅助风扇。
2. 断电后将辅助风扇连接到独立 **FAN3（PC9）**，核对插头、电压和极性；主模型风扇保留 **FAN2（PB7）**。
3. 配置独立控制通道和 Bambu Studio 指令映射，分别测试主、辅助风扇的开启、关闭及调速，确认互不带动。

这项改动让 Bambu Studio 的“辅助部件冷却风扇”可以独立控制。风扇必须实际分接到不同输出，软件映射才能实现独立调速。

### 4. 步进驱动专用散热风扇

1. 断电后，将原接在 **FAN6** 的驱动散热风扇改接到 **FAN4（PA8）**，保留原热端散热风扇及其控制方式。
2. 原厂 FAN1 与 FAN6 共用 **PC7** 输出，移到 FAN4 后，驱动风扇能够独立控制，不再依赖热端温度启动。
3. 用 Klipper `controller_fan` 监控 X、Y、两侧 Z 和挤出机：任一受监控电机使能时开启，全部释放后延时关闭；参考配置延时为 60 秒。
4. 验证风扇实际转动及延时关闭，并确认热端散热仍正常。

**使能包含电机静止时的保持状态。** 龙门不移动但 Z 电机仍保持时，驱动散热风扇继续运行属于正常行为。

### 5. ADXL 自动 Z-offset 与床网温漂修正

这两项主要通过配套软件和标定实现，参考方案没有为此增加传感器：

- 自动 Z-offset 复用原厂工具头上的 **ADXL345**，检测清洁喷嘴接触钢板时的响应。
- 床网和温漂修正使用原厂接近传感器，利用追加的参考测量估计漂移，无需另装温度传感器。

实施前应检查目标机器是否具备对应传感器、连接是否正常及软件版本是否匹配。ADXL 接触测量需要部署项目的配套代码，再校准触发条件和受控下探范围；硬件装好并不代表可以直接运行参考开始代码。

## 装配完成后的基本检查

所有驱动模块、电机线、跳线和风扇接线改动均应在完全断电后进行，电机或驱动模块不得带电插拔。

上电前核对驱动方向、端子线序和锁止、线束绝缘、散热片固定及风道；检查擦嘴条和线束在工具头、热床全行程内不会干涉。先保留原接线照片和软件备份，之后按项目验收流程逐项检查。

**每次上电或重启 Klipper 后，在安全归位条件具备时先完成真实 Home，再做后续 XYZ 移动或床网校准。** 默认坐标或界面“已归零”不能代替实体归位。新增驱动方向、探针或空间条件仍不明确时，先处理检查项，不能盲目归位；未完成真实归位时，使用者也不要随意移动工具头或点击网页端床网校准。

完整参考方案仍需逐项完成通信、侧别和方向、风扇、擦嘴位置、传感器及首层验证。不同生产批次和既有改装可能存在差异，应按实际机器调整配件、接线和软件配置。
