# Bambu Studio 项目与首尾代码

## 导入

`slicer/naptune4max.3mf` 是 Bambu Studio 项目，不是安装打印机端软件的程序。参考保存版本 `02.08.02.60`，Elegoo Neptune 4 Max 0.4 nozzle，自定义工艺和 Generic PETG。选择“打开项目”载入项目设置，检查后另存为自己的用户预设；不要仅导入其中模型并期望打印机配置随之载入。

项目保留 3DBenchy。公开副本清除了模型 metadata 的 DesignerUserId；没有改变网格、项目设置或首尾代码。原始输入文件保持不变，导出哈希和清理记录见 `slicer/export-report.json`。

配方的温度、流量、回抽、速度和 PA 是参考条件，不代表每种材料的最佳值。导入后使用自己的打印机地址、耗材与已完成校准的参数。

## 开始代码的关键参数

`ADXL_Z_OFFSET_PREPARE_WIPE` 从 Bambu 获取首层床温，SOAK=300，建立一次性擦嘴会话。双 Z wrapper 在准备后、擦嘴和新床网前校正龙门，所以完整方案无需再额外插入 Z_TILT。

`ADXL bed heat soak` 是热稳定进度：床温进入目标 ±1°C 后连续保持 300 秒，超出范围重新计时，准备喷嘴为 140°C。`stable=120/300s` 表示已稳定 120 秒。详见[热稳定日志说明](features.md#热床稳定等待与控制台日志)；不要因暂时没有运动就重复启动开始流程。

所给文件先 Z10/X0，随后还有 `G1 Z2 F300` 再排料100mm，旧注释仍有“保持 Z10”的描述；**以实际指令为准**。排料线拉断后回抽10mm，再Z10，沿左侧到Y430硅胶条。X10～30、Z-0.5、临时offset-2、两轮高速擦嘴都要求自己的支架几何和间隙校准。

清理临时offset后建立 adaptive profile；正式ADXL要求相同床温、SOAK=0、AFTER_WIPE=1、FUZZ=3，不再重复五分钟热稳定等待，但仍检查温度。X、Y 各在中心±3mm范围选一个随机点，三Tap及内部重试沿用该点，下次校准再选，以分散重复接触的位置；床网已经预留覆盖。详见[随机接触说明](features.md#随机接触点与局部磨损)。最后 `Z_ADJUST=0.140` 是参考机主首层实测补偿，其他机器应自行确定。

## 原文件保留的已知适配事项

首尾文件有 `SET_SKEW CLEAR=1`。参考机器当前命令表里没有 SET_SKEW；在相同环境中可生成去掉这行的目标模板，若目标确实配置了 skew_correction 则按目标处理。不要仅为消除一行指令而改变原机器的偏斜补偿配置。

结束代码的 `;PRINT_END` 是注释，**没有执行 PRINT_END 宏**。结束代码通过 `M106 S0` 只关闭主风扇，不能保证 PC9 辅助风扇停止。为目标生成结束模板时，在风扇路由已存在的条件下使用 `M107` 关闭两者，或额外 `M106 P2 S0`；不把原文件误写成已经具备该行为。本次没有修改参考打印机或用户原始文件。

参考结束模板停车后清床网、关热、`M84 X Y E` 保持两个Z电机。故障/取消/空闲等其他路径可能释放Z，不能据此认为所有退出路径都保持龙门高度。`SET_VELOCITY_LIMIT` 的旧版本 ACCEL_TO_DECEL 参数也需目标接口核对。

结束代码在停车前恢复参考运动限值，避免文件末次 `M204` 留下的低加速度影响停车及下一任务。ADXL 探测后恢复的是进入探测时的加速度，不会自动重读 printer.cfg 的基准。适配时使用目标机器的基准并核对实际生成文件，见[跨任务加速度经验](lessons-learned.md#上一任务的加速度可能影响下一次打印)。

## 初次使用

先完成软件 Ready、真实归零、两侧正向抬升、PA11、擦嘴几何和 ADXL 接触窗口验证，再运行完整开始流程。仅导入3MF不能完成这些条件。智能体应向用户解释选中的动作、等待和可停止方式，不把“导入成功”作为打印验收。

辅助冷却需要耗材设置中有非零辅助风扇参数，输出 `M106 P2` 才能使用PC9。主模型风扇的界面100%对应70% PWM，辅助100%对应100% PWM。

`slicer/COLD_PULL_150mm_90C.gcode` 是展开动作的维护文件。运行它会加热、运动和挤出；应先了解材料配方和90°C低温回抽条件。不能把文件简写为COLD_PULL宏调用，因为virtual SD启动后宏的空闲状态保护会拒绝。
